# PetGuardian-IoT

Sistema IoT para rastreamento e segurança de pets, utilizando ESP32, botão SOS, display OLED, LEDs e buzzer.

## Objetivo

Desenvolver um protótipo funcional de uma coleira inteligente capaz de indicar o estado do pet e acionar alertas em situações de risco.

## Funcionalidades

- Indicação de área segura
- Indicação de área perigosa
- Botão SOS
- Alerta sonoro com buzzer
- LEDs de status
- Display OLED com mensagens do sistema

## Componentes

- ESP32
- Display OLED SSD1306
- Pushbutton
- LED verde
- LED vermelho
- Buzzer

## Tecnologias

- Wokwi
- C++
- ESP32
- IoT
- OLED SSD1306
